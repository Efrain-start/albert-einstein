# 🌌 Proyecto: Albert Einstein

Este proyecto es una **página web informativa** sobre la vida, obra y legado de **Albert Einstein**, uno de los científicos más influyentes de la historia.  

Incluye secciones dedicadas a:  
- 📖 **Biografía**: sus orígenes, estudios y vida personal.  
- 🔬 **Contribuciones científicas**: teorías más importantes, como la **Relatividad Especial y General**.  
- 🏆 **Logros y reconocimientos**: premios y aportaciones a la humanidad.  
- 💡 **Frases célebres** que inspiran a generaciones.  

---

## 🚀 Tecnologías utilizadas
- **HTML5** para la estructura del contenido.  
- **CSS3** para los estilos y diseño visual.  

---

## 🎯 Objetivo
El objetivo de este proyecto es **practicar diseño web** y al mismo tiempo difundir información educativa sobre Albert Einstein.
